# Outline в Serpium

Для своего VPS подготовлен отдельный [серверный комплект](../Server/README.md):
Outline-совместимый Shadowsocks или VLESS/REALITY, отдельные ключи пользователей,
проверка конфигурации до запуска и откат при ошибке применения.

На главном экране доступны «Мои ключи» и «Автоподбор Outline».

## Мои ключи

Поддерживаются обычные `ss://` ключи Shadowsocks (SIP002 и старый Base64-формат),
в том числе IPv6, и методы AES-128/192/256-GCM и ChaCha20-IETF-Poly1305.
`ssconf://` может указывать на обычный ключ или стандартный JSON с полями
server, server_port, method, password. HTTPS-подписки могут содержать список
обычных ключей, его Base64-представление или такой JSON.

Параметр `prefix` в статических `ss://` ключах поддерживается через комплектный
`Serpium.Outline.exe` на официальном Outline SDK v0.1.0. Prefix применяется только
к TCP; UDP сохраняет стандартный Shadowsocks. Percent-encoding сначала декодируется
из UTF-8, затем символы U+0000–U+00FF становятся байтами. Не более 16 байт prefix;
в соли остаётся не менее 16 случайных байт (для AES-128-GCM prefix не разрешён).
Копия схемы `ss\://` из форматированного сообщения также распознаётся.

Модуль слушает только loopback, получает ключ через stdin и использует отдельный
случайный локальный пароль на каждое подключение. При отключении VPN, отмене проверки
или закрытии приложения его соединения закрываются. Конфигурация остаётся в памяти;
в профиле она сохраняется в существующем зашифрованном хранилище. Список приложений
и переключение маршрутов продолжает обслуживать sing-box/SFP.

Расширенные Outline YAML, prefix в динамическом JSON, плагины и Shadowsocks-over-WebSocket пока
не поддерживаются; параметры, меняющие транспорт, не отбрасываются молча.
Ручной импорт динамической ссылки сохраняет снимок полученного профиля.
Для обновления его параметров нужно импортировать ссылку заново. Автоподбор
загружает источник заново при каждом нажатии «Подобрать и подключиться».

## Автоподбор

Источник — указанная пользователем HTTPS-ссылка на открытый список ключей
или публичный Telegram-канал с готовыми ключами в сообщениях. По умолчанию
используется `https://t.me/s/outlinevpn_ru`, предложенный пользователем.
На момент проверки 22.10.2026 этот канал перенаправляет на страницу выдачи
с проверкой браузера/капчей. Из него сейчас нельзя автоматически получить
ключ: нужно вручную получить ключ либо указать другой прямой источник.
Произвольные внешние ссылки из канала не обходятся. Скрипты страницы,
вход в Telegram, отправка сообщений ботам и обход капчи не выполняются.

Проверяются до 8 разных кандидатов последовательно; до 15 секунд на кандидат,
до 2 минут на весь перебор, отдельно ограничена загрузка источника.
Выбирается первый кандидат, подтвердивший HTTPS-доступ через Shadowsocks.
Это проверка работоспособности сейчас, а не измерение самого быстрого сервера.
Постоянного фонового сканирования и переключения работающего VPN нет.

Во время подбора кнопка «Стоп» отменяет операцию. Каждый тестовый процесс
sing-box получает настройки через stdin и запускает только защищённый паролем
локальный SOCKS5-прокси, без TUN и изменения системных маршрутов. Процесс
завершается до перехода к следующему кандидату. Рабочий ключ сохраняется
через существующее DPAPI-хранилище; затем запускается обычное подключение
с выборочной маршрутизацией и повторной проверкой связи. Автоматический
режим остаётся выбранным для следующего подключения.

Источник и найденные ключи не записываются в журнал, исходники или publish.
Пользовательский адрес источника остаётся в памяти до закрытия приложения.
HTTP, локальные адреса источника, приватные DNS-ответы, небезопасные
перенаправления и чрезмерно большие ответы запрещены. `ss://` и `ssconf://`
маскируются общим фильтром диагностик.

## Проверки

`dotnet run --project Tests/Outline/OutlineChecks.csproj -c Release -- <папка результатов> <путь к sing-box.exe>`

Проверки используют искусственные ключи, подставной HTTP-источник, отдельное
тестовое хранилище и локальный Shadowsocks-сервер. Реальные пользовательские
профили и маршруты Windows не изменяются. Результат включает проверку
реального обмена через SOCKS5 + Shadowsocks и снимки обеих тем WPF.
Интернет-подключение с ключом из указанного канала не проверено: канал не
предоставил доступный для автоматического получения ключ.
