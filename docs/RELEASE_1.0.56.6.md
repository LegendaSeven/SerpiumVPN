# SerpiumVPN 1.0.56.6

- Новый компактный интерфейс, две темы и обновлённый логотип.
- Сохранённые профили над полем ключа, выбор профиля, индивидуальное и групповое удаление. Поле ключа блокируется при выборе сохранённого профиля.
- Импорт ключей и HTTPS-подписок, проверка соединения перед подтверждением подключения, кнопка «Стоп» и понятные ошибки.
- Обнаружение пользовательских сетевых приложений; переключение выбранного приложения между VPN и прямым подключением с закрытием его старых интернет-соединений.
- Защищённое хранение профилей средствами Windows, маскировка ввода и сокрытие секретов в диагностике.
- Проверка обновлений sing-box и Xray, проверка совместимости и сохранение/восстановление предыдущей версии при ошибке.
- Удалена интеграция Zapret. Исправлена полнота комплекта модулей в установщике.

Windows x64. Установщик включает .NET; отдельная установка среды не требуется. ZIP предназначен для обновления/ручного развёртывания.

Проверки: 350 успешных автоматических проверок текущего кода; конфигурации нативных движков, локальные TCP/UDP-соединения, переключение правил, профили, отмена подключения и откат компонентов. Доступность серверов конкретной подписки зависит от её провайдера и не подтверждается этими тестами.

Экспериментальный драйвер WFP включён как неустановленный компонент. Установщик не регистрирует и не запускает его; основной интерфейс использует TUN. Его сборка содержит предупреждения компилятора; это не подтверждение готовности драйвера к эксплуатации.
