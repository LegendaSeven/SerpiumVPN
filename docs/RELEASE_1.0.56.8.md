## SerpiumVPN 1.0.56.8

Исправлен сбой запуска при загрузке иконки трея. Иконка окна, EXE, трея и ярлыков использует новый логотип Serpium; при недоступном изображении трея приложение продолжает запуск со стандартной иконкой.

Из проекта и установщика удалены неиспользуемые SerpiumNet, Telegram-прокси, демонстрационные плагины, SDK и экспериментальные драйверы. Основной VPN работает через Xray и sing-box TUN с переключением приложений через SFP live routing. Сохранённые профили и настройки сохраняются.

Обновлятор очищает только известные устаревшие файлы программы. Проверка совместимости обновлений sing-box и Xray, остановка подключения и переключение маршрутов остаются доступны.

### Проверено

- Сборка приложения и установщика; состав ZIP и контрольные суммы.
- Профили, импорт ключей, безопасность, остановка подключения, маршруты TCP/UDP и совместимость обновлений.
- Воспроизведение ошибки иконки в контексте настоящего EXE и прохождение проверки после исправления.
- Запуск готового EXE 1.0.56.8: процесс работает, главное окно создано, новой ошибки запуска в журнале Windows нет.

Подключение к реальному VPN-провайдеру с действующим ключом и установка на чистой Windows в этом проходе не проверялись.
