# Обновление Serpium

В верхнем меню **Обновления** находятся два отдельных блока: Serpium и компоненты sing-box/Xray.

Serpium проверяет последний стабильный выпуск `LegendaSeven/SerpiumVPN` при запуске и каждые шесть часов. Проверку можно отключить переключателем **Проверять автоматически** или запустить вручную. Проверка загружает только сведения о выпуске. Кнопка **Скачать обновление** показывает ход загрузки и позволяет отменить её. После проверки пакета появляется **Установить и перезапустить**. Установка требует подтверждения; активный VPN отключается перед выходом. После перезапуска пользователь подключается снова.

Готовое обновление остаётся доступным в меню, в том числе при включённом VPN. Ошибки показываются в том же блоке. Неполные загрузки удаляются. Если приложение закрыто без установки, проверенный архив также удаляется; при следующем запуске его можно скачать заново.

## Требования к выпуску

- Стабильный GitHub Release с числовой версией из трёх или четырёх частей.
- `update.json` с полями `version`, `zipUrl`, обязательным `sha256`.
- `SerpiumVPN-<version>.zip` в этом же выпуске; адрес, версия и размер сверяются с GitHub. Если GitHub возвращает SHA-256 asset, он также должен совпадать.
- Корень ZIP содержит приложение, `SerpiumUpdater.exe`, иконку и оба транспорта. Штатный `release.ps1` создаёт соответствующий пакет со средой .NET.

Скачанный архив хранится во временной папке с доступом текущего пользователя и SYSTEM. SHA-256 и состав пакета проверяются перед установкой повторно. В ZIP не допускаются выход за пределы папки, ссылки, дубликаты путей, пользовательские профили и настройки. Перед заменой файлов создаются резервные копии; при ошибке замены предыдущие файлы восстанавливаются. Это откат файловой операции, а не гарантия восстановления после отключения питания. При невозможности отката резервная копия сохраняется и показывается сообщение об ошибке.

Профили и привязки устройств не передаются в GitHub. Установка не очищает пользовательское хранилище и оставляет `bin_files/serpium.runtime.json`. Проверки находятся в `Tests/Updates`.
