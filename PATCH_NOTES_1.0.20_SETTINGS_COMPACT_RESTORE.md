# SerpiumVPN v1.0.20 — Settings Compact Restore

- The square title-bar button no longer opens fullscreen mode.
- The square button restores the Settings window to 860×820.
- The restored window is centered inside the Windows work area.
- Manual resizing remains available within a safe compact range.
- Minimize and hide-on-close behavior remain unchanged.
- Relay Gateway, Client, keys, logs, and SOCKS session remain active while the window is hidden.
