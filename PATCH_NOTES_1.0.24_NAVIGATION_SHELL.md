# SerpiumVPN v1.0.24 — Navigation Shell

Первый безопасный этап перехода к модульному интерфейсу.

## Добавлено

- Левая навигация:
  - Главная
  - Zapret
  - Serpium Relay
  - Настройки
- Текущий рабочий интерфейс полностью сохранён на странице «Главная».
- Страницы Zapret и Serpium Relay пока являются визуальными заглушками.
- Страница «Настройки» содержит кнопку открытия текущего SettingsWindow.
- Размер окна увеличен под новый навигационный каркас.

## Не изменено

- ZapretManager и стратегии.
- TelegramProxyManager.
- Relay/Xray-сессии.
- Логика обновлений.
- Tray lifecycle и завершение процесса.
- MainWindow.xaml.cs.

## Защита патча

- Проверяются ключевые элементы текущего MainWindow.xaml.
- Перед заменой создаётся резервная копия.
- При неудачной сборке исходный MainWindow.xaml восстанавливается автоматически.
